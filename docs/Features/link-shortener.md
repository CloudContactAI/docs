To prevent abuse, this is a feature that is currently locked behind a paywall.  The link shortener will have its own dedicated spot on the side menu.

After selecting the '+Create Short Link' option, the process is just a matter of copying over the URL to be obscured and saving.  The user will then be sent back to the previous screen.

The shortened URL will now appear on the UI with the actual link, what the representative URL is, and records for how many hits the link has received and when it was last accessed by a contact.  There is a clipboard icon in the middle for users to copy the shortened link from.
