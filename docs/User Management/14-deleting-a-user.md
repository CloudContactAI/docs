If a user needs to be removed, first go down to the Admin tab and start at the users table.

![1685](https://files.readme.io/222acff-User_Signed_In.png "User Signed In.png")

For everyone who isn't the account owner, there is a red trash can icon.

![531](https://files.readme.io/46a7c38-Remove_User.png "Remove User.png")

In case the account owner chose the wrong user to remove, there is one more confirmation splash screen to verify the deletion.

![1106](https://files.readme.io/2494a47-Remove_User_Confirmation.png "Remove User Confirmation.png")

Once that is done, the user will be completely removed, but can be invited back onto the account.

![408](https://files.readme.io/2ab62a4-Remove_User_Successful.png "Remove User Successful.png")
