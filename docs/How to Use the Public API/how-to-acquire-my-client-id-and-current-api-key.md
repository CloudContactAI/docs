1. Launch [CloudContactAI](https://www.cloudcontactai.com)
2. Navigate to the Settings menu item in the navigation bar
3. Click on the Security Tab
4. Click on the "New API Key" button
5. Click on the "Copy API Key" button
6. Store the Client ID and API Key for use in Postman or CURL
